01 Automation · Jira · Claude API

Onboarding Roundup Agent

Every new hire generates a web of Jira tickets — IT setup, system access, equipment, buddy assignments, training schedules. Each ticket has an owner. Every owner needs to know what they're responsible for.

Before this tool, I was manually cross-referencing tickets, figuring out who owned what, and composing individual messages for each team member. Multiple times a week. 30+ minutes each time.

This agent reads all open onboarding tickets, maps actions to owners, accounts for dependencies and edge cases, and drafts a personalized message per team member — complete and ready to send.

30+ minutes saved per session
100% coverage across all action owners

02 AI Drafting · Onboarding · Claude API

Welcome Email Drafter

First impressions matter. A new hire's welcome email should feel warm, specific, and human — not like it was copy-pasted from a template.

This tool takes two inputs: the offer letter request and the offer letter itself. From those, it extracts the relevant details and drafts a complete, personalized welcome email ready to review and send. No reformatting. No manual extraction. No blank-page moment.

03 Systems · Automation · Claude API · n8n

Onboarding Workflow Generator

When a candidate is marked hired, People Ops shouldn't have to do anything. This tool demonstrates what a fully triggered onboarding workflow looks like — from Ashby to Rippling to the hiring manager's inbox — with Claude as the intelligent layer in the middle.

The key insight: generic onboarding templates fail because they're built at the department level. By passing the job description to Claude as a primary input, every output is specific to the role — the hiring manager brief, the new hire guide, and the IT and finance checklist all reflect what that person will actually be doing on day one.

In a full production build, this triggers automatically via Ashby webhook → n8n → Claude API → Rippling and Jira. The interactive demo below shows the Claude output layer live.
