01 Automation · Jira · Claude API

Onboarding Roundup Agent

Every new hire generates a web of Jira tickets — IT setup, system access, equipment, buddy assignments, training schedules. Each ticket has an owner. Every owner needs to know what they're responsible for.

Before this tool, I was manually cross-referencing tickets, figuring out who owned what, and composing individual messages for each team member. Multiple times a week. 30+ minutes each time.

This agent reads all open onboarding tickets, maps actions to owners, accounts for dependencies and edge cases, and drafts a personalized message per team member — complete and ready to send.

03 Systems · Automation · Claude API · n8n

Onboarding Workflow Generator

Rippling's native onboarding workflows handle repeatable, role-agnostic tasks well. What they can't do is generate content specific to the role — a hiring manager brief tailored to what this person will actually be doing, or a first-week guide that reflects the job description rather than just the department.

This proof of concept sits in that gap. A hire in Ashby triggers n8n, which passes the job description to Claude. Claude generates role-specific outputs: a hiring manager brief, a new hire guide, and a task list. The hiring manager reviews and approves — a deliberate human-in-the-loop checkpoint to ensure quality before anything gets committed. Approved tasks are then written back into Rippling as onboarding workflow items via API, so everything lives in one place and nothing duplicates what's already there.

The interactive demo shows the Claude output layer. The architecture document covers the full flow.

1 human checkpoint, zero redundancy
3 role-specific outputs generated
